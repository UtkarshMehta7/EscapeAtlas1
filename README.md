# EscapeAtlas

> Your Adventure Starts Here - Explore, Dream, Discover with EscapeAtlas

A travel website built with HTML and CSS. The home page has a photo grid of places in India, and each photo opens a full guide to that destination with its history, culture, attractions, a photo gallery and visitor tips. Visitors can then send a trip inquiry.

## Features

- **Photo grid** where every image links to its destination guide
- **Destination guides** with history, culture, attractions, an image gallery and visitor information
- **Popular tours** cards for Australia, the Maldives, Paris, Dubai, India and Italy
- **Services** and **Why us** sections
- **Book now** call to action that links to the inquiry form
- **Inquiry form** with client-side validation and a success message (demo only, nothing is sent)

## Stack

- HTML5
- CSS3 (`first.css`, `style.css`, `style2.css`, `style3.css`)
- Vanilla JavaScript for the form

## Run locally

No build step is needed. Clone the repo and open `index.html` in a browser:

```bash
git clone https://github.com/UtkarshMehta7/EscapeAtlas1.git
cd EscapeAtlas1
open index.html
```

On Windows use `start index.html`, and on Linux use `xdg-open index.html`.
